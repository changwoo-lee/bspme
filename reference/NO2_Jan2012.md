# Daily average NO2 concentrations in and around the Harris County, Texas, in Jan 2012

This dataset contains daily average NO2 (nitrogen dioxide)
concentrations obtained from 21 monitoring stations in and around Harris
County, Texas, in January 2012.

## Usage

``` r
data(NO2_Jan2012)
```

## Format

A data frame with 651 (21 sites x 31 days) rows and 5 variables:

- date:

  date in POSIXct format

- site_name:

  monitoring station name

- lon:

  monitoring station longitude

- lat:

  monitoring station latitude

- lnNO2:

  natural logarithm of daily average NO2 concentrations measured in
  parts per billion by volume (ppbv)
